# 🛒 SmartPrice – Smart Product Price Tracker

**SmartPrice** is a web-based price tracking and comparison platform that helps users find the best deals across multiple e-commerce websites. It allows users to track product prices, compare prices across platforms, and monitor historical price changes to make smarter purchasing decisions.

## ✨ Features

- **Price Tracking:** Track product prices by providing product URLs.
- **Product Information Extraction:** Automatically extract product details, including product names, prices, and images using Firecrawl.
- **Price History:** Monitor and maintain historical product price data to identify price fluctuations.
- **Multi-Platform Price Comparison** *(Under Development):* Compare the prices of the same product across multiple e-commerce platforms.
- **Comparison Tables** *(Under Development):* View product prices from different shopping platforms in a structured comparison table.
- **Smart Shopping:** Help users make informed purchasing decisions by tracking price changes and identifying better deals.

## 🚀 Project Goals

The primary goal of SmartPrice is to simplify online shopping by eliminating the need to manually visit multiple e-commerce websites to compare product prices.

The platform aims to provide a centralized solution for price monitoring, product comparison, and price history analysis.

## ⚙️ Getting Started

### Prerequisites

- Git
- Node.js and npm (if using a Node.js-based setup)
- Required API credentials

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/SmartPrice.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SmartPrice
   ```

3. Install the dependencies using the package manager configured for your project.

4. Configure your environment variables.

   Create a `.env` file in the appropriate directory and add your required API keys and database configuration.

   Example:

   ```env
   FIRECRAWL_API_KEY=your_firecrawl_api_key
   ```

5. Start the application using the appropriate development command for your project.
